# Project NEXUS - Coding Plan

> 生成日期: 2025-02-17
> 版本: v1.0

---

## 背景

Project NEXUS 是一个个人 CRM 系统，后端运行在 Node.js 上，通过 Telegram Bot 与用户交互，数据存储在 Obsidian Vault 中。

当前问题：
- 依赖手动配置 `.env` 文件
- 需要命令行操作启动
- 无法快速部署到新设备

### 2. 简化部署流程

**目标**: 像安装 App 一样简单的部署体验

#### 2.1 交互式配置向导

启动时检测未配置项，提示用户依次输入：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| Telegram Bot Token | @BotFather 创建 | 123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11 |
| Telegram Chat ID | 用户 ID | 6573965713 |
| MiniMax API Key | 模型 API | sk-xxx... |
| Finnhub API Key | 美股新闻 (可选) | abc123... |
| Obsidian Vault 路径 | Vault 位置 | ~/Library/.../Nexus-Vault |
| Telegram 代理 (可选) | 国内需要 | http://127.0.0.1:7890 |

#### 2.2 一键安装脚本


安装脚本自动完成：

### 3. 优化启动方式

**目标**: 告别命令行，像打开 App 一样启动

#### 3.1 macOS App 包装

使用 **Electron** 或 **Pkg** 打包成 `.app`：

```
📦 NEXUS.app
├── Contents
│   ├── MacOS/NEXUS          # 可执行文件
│   ├── Resources/           # 静态资源
│   └── Info.plist
```

用户双击 `.app` → 自动启动 Bot

#### 3.2 启动器 UI

如果用 Electron，可以做一个小窗口：

```
┌─────────────────────────────┐
│  🔷 NEXUS CRM              │
│                             │
│  Status: Running ✅         │
│                             │
│  Uptime: 2h 34m            │
│                             │
│  [Open Dashboard]          │
│  [View Logs]               │
│  [Quit]                    │
└─────────────────────────────┘
```

#### 3.3 替代方案: LaunchAgent

如果不想用 Electron，可以创建 macOS LaunchAgent：

```xml
# ~/Library/LaunchAgents/com.nexus.crm.plist
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key><string>com.nexus.crm</string>
    <key>ProgramArguments</key>
    <array>
        <string>/path/to/nexus/start.sh</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
</dict>
</plist>
```

用户把 App 拖到 Applications 文件夹 → 系统启动时自动运行

## 技术方案

### 部署架构

```
┌─────────────────────────────────────────────────────────┐
│                    用户设备 (Mac)                       │
│                                                         │
│   ┌──────────────────────────────────────────────┐     │
│   │  NEXUS App / LaunchAgent                     │     │
│   │                                              │     │
│   │  ├── Node.js (Bot + API)                    │     │
│   │  ├── TypeScript 编译                         │     │
│   │  ├── SQLite (本地数据库)                     │     │
│   │  └── Obsidian Vault (通过 iCloud 或本地)     │     │
│   └──────────────────────────────────────────────┘     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 文件结构 (部署后)

```
~/nexus/
├── .env                 # 用户配置 (不提交)
├── dist/                # 编译后的 JS
├── node_modules/        # 依赖
└── data/
    └── nexus.db         # SQLite 数据库

~/Library/LaunchAgents/
└── com.nexus.crm.plist  # 开机启动
```

## 风险与注意事项

1. **API Key 安全**: `.env` 不提交到 GitHub
2. **Obsidian 路径**: 不同设备路径不同，需要用户配置
3. **Telegram 代理**: 国内用户需要配置代理
4. **数据库迁移**: SQLite 文件需要手动备份/迁移
